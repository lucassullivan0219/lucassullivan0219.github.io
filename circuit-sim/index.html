電路互動模擬器（概念示範）

把 HW2 主動膜模擬的作法（修正節點分析＋Newton 迭代＋隱式積分）做成通用引擎：電路用文字描述、電路圖自動畫出來，可以邊跑邊改元件、按開關、量節點，也能做 AC 掃頻、DC 掃描、雜訊分析和蒙地卡羅。下面八個範例各自示範一組功能；最後一個就是 HW2 的電路，結果和 Python 版逐點相符。

範例

電路圖（點元件改數值、點導線量電壓）

元件與節點

點電路圖上的元件可以調整數值；點導線或標籤可以把那個節點加到示波器。

節點電壓

在 DC 工作點把每個非線性元件線性化，再對每個頻率解複數方程 (G + jωC)x = b。輸入源的振幅當作 1。

每一點都重解 DC 工作點（從上一點的解出發，跟 SPICE 的 .dc 一樣）。電容開路、電感短路，交流源取它的直流值。

伴隨（adjoint）法：每個頻率只解一次 Yᵀy = e_out，就得到所有雜訊源到輸出的轉移。雜訊源：電阻 4kT/R、二極體與 BJT 散粒雜訊 2qI、運放 EN／IN。

電路文字（可以直接改）

格式說明

一行一個東西，座標是整數格點 x,y（往右、往下為正）。兩個點落在同一格點就接在一起。

  • R R1 0,0 4,0 1k：兩腳元件 R、C、L、V、I、D、SW；V、I 的第一點是 + 端。
  • V V1 0,0 0,6 SIN(0 1 1k) AC=1：波形 SIN／PULSE／SQUARE／PWL，AC= 是 AC 分析的振幅。
  • Q Q1 10,5 npn [h] BF=200：錨點是基極，集極 (+2,−2)、射極 (+2,+2)；[h] 左右翻、[v] 上下翻。
  • U U1 6,5 GBW=1meg VMAX=5 VMIN=-5 EN=10n：錨點是 − 輸入，+ 輸入在 (0,+1)，輸出在 (+4,0)。
  • W 0,6 6,6 導線、GND 0,6 接地、NODE vout 6,0 網路標籤（同名就相連）。
  • SW S1 2,0 4,0 off MOM=1：開關；MOM=1 是按住才導通。
  • 數值用 SPICE 字尾：f p n u m k meg（m 是 milli，百萬要寫 meg）。

原本的 Active membrane 模擬是怎麼做的

  
    
    
  1. 照 PCB 寫出電路：每個節點一個名字（ST.Q、FI.B3…），每顆元件一行。開關、排針接點用電阻代表：接上 0.05 Ω、斷開 10¹³ Ω，所以「哪根針沒插好」只是改一個數字。
    2. 
    
  2. 修正節點分析（MNA）：對每個節點寫 KCL「流出的電流總和 = 0」。電阻是線性項；二極體、BJT 用 Ebers–Moll 指數模型，是非線性項。
    3. 
    
  3. Newton–Raphson：每一步解 J·Δx = −F（J 是 Jacobian），再更新電壓；每次迭代電壓最多走 0.1 V，避免指數爆掉（阻尼 Newton）。每個節點對地掛 10⁻¹² S（gmin），浮接的節點才解得出來；DC 解不出來時改用 gmin stepping。
    4. 
    
  4. 電容用 backward Euler：i = C·(v − v_prev)/Δt，等於一個電導加一個電流源，Δt = 0.2 ms。
    5. 
    
  5. Python 先驗證（hw2-debug/sim/）：DC 對照萬用電表量測、暫態對照示波器、蒙地卡羅換 β 與 Is 看結論穩不穩。
    6. 
    
  6. 再搬到瀏覽器：同一組方程式改寫成 JavaScript，每個畫面更新跑約 80 步（0.2 ms × 80 ≈ 16 ms），剛好跟真實時間同步；示波器是環形緩衝區加 Roll／Single 觸發，電路圖是手畫的 SVG，節點電壓即時填進去。
    7. 
  


  
原本那版的極限

  
    
    
  • 電路寫死在程式裡：19 個節點、每顆元件的 stamp 都是手寫的；電路圖是另外手畫的 SVG，和模擬是兩份東西，改電路要改兩處，可能對不上。
    • 
    
  • 元件模型很簡化：Ebers–Moll 只有 DC 行為，沒有接面電容、Early 效應、溫度；參數是典型值，不是你手上那幾顆。所以快速邊緣（µs 級）和精確的震盪門檻都不可信。
    • 
    
  • 固定步長 backward Euler：沒有誤差控制，Δt 太大會人工阻尼（振盪變小、峰值變低）；剛好在「會不會震盪」邊緣的情況（按住 SW 時 40 Hz 震盪）對 Δt 和參數都很敏感。
    • 
    
  • 只有暫態：沒有 AC、雜訊、靈敏度分析；沒有 60 Hz 雜訊、麵包板寄生電容、示波器頻寬。
    • 
    
  • 稠密矩陣 O(N³)：19 個節點每步只要微秒；幾百個節點以上就要稀疏矩陣。
    • 
    
  • 沒有和 SPICE 交叉驗證：只和量測與自己比。
    • 
  


  
這個通用版補上了什麼（對照範例）

  

  

    
功能怎麼做看哪個範例

    
      
文字描述電路、自動畫圖座標決定接線（union-find），網路標籤同名相連；電路圖和模擬來自同一份文字，不會對不上。全部；Netlist 分頁可以直接改

      
即時暫態＋示波器每個畫面跑到時間預算用完；跟不上時自動變慢動作，狀態列顯示實際倍率。RC、RLC、多諧振盪器

      
電壓顏色、電流動畫導線依節點電壓上色；導線上的電流用 KCL 沿樹狀走線推回來。RC、整流

      
邊跑邊改元件、按開關改參數只重算矩陣，不重建電路；MOM 開關按住才導通。HW2 主動膜、生醫前端

      
兩種積分法Backward Euler 穩但有數值阻尼；梯形法準但會在不連續處振鈴。RLC（Δt 改 50 µs 比較）

      
非線性收斂DC：阻尼 Newton → gmin stepping → source stepping，和 SPICE 的順序一樣。暫態：某一步 Newton 不收斂就把步長切成 1/8、1/32…（最小到 ps），成功後再加倍，切換瞬間自動加密。整流、多諧振盪器

      
運放巨集模型gm 級＋單極點（A₀、GBW）＋軟性電源軌限制（softplus）＋輸出電阻／限流。運放、生醫前端

      
AC 掃頻在工作點線性化，解 (G + jωC)x = b。RC、RLC、BJT、運放

      
雜訊分析伴隨法；積分出指定頻寬的 µVrms、列出每個元件的貢獻。運放、生醫前端

      
DC 掃描沿用上一點的解做延拓。整流、BJT、運放

      
蒙地卡羅電阻、電容、β 隨機抽樣，看規格分布（例如 CMRR）。BJT、生醫前端

      
SPICE 匯出、分享連結產生 netlist 給 LTspice／ngspice 對照；電路文字可以編進網址。Netlist 分頁

    
  

  


  
這個版本仍然做不到的

  
    
    
  • 元件模型還是教學等級：BJT／二極體的接面電容是固定值（不隨偏壓變），沒有 Early 效應、擴散電容、溫度；MOSFET 是 level 1。
    • 
    
  • 步長只在 Newton 失敗時才縮小，沒有局部截斷誤差控制：波形變化快但仍收斂時，準確度由你選的步長決定。
    • 
    
  • 稠密 LU，超過約 100 個未知數就會慢；沒有子電路（.subckt）和 .model 檔匯入。
    • 
    
  • 電路圖不能拖拉編輯，只能改文字；元件一律水平或垂直擺放比較好看。
    • 
    
  • 雜訊沒有 1/f 以外的頻率相依模型（電極雜訊、運放的 1/f 用 FC 參數近似）；沒有失真（.four）、靈敏度、極零點分析。
    • 
  


  
可以考慮的開發方向

  

    
拖拉式電路圖編輯
資料模型已經是「元件＋座標」，加上選取、拖曳、旋轉、從元件庫拉出來，就是完整的編輯器。
價值高 · 工作量中

    
ngspice（WebAssembly）當第二引擎
同一份 netlist 丟給編譯成 wasm 的 ngspice，用真的 SPICE 模型（.model、.subckt、廠商模型）交叉驗證，教學版引擎負責即時互動。
價值高 · 工作量中（wasm 檔約數 MB）

    
可變步長與誤差控制
用 BE／梯形法的差估計局部截斷誤差，自動調 Δt；開關、脈波邊緣自動加密。快慢混合的電路（神經元、開關電源）準很多。
價值中 · 工作量中

    
稀疏矩陣＋Web Worker
大電路改用稀疏 LU（KLU 式），模擬放到 Worker 不卡畫面；8 通道 EEG 前端整個做暫態就跑得動。
價值中 · 工作量中

    
量測資料疊圖
把 NEEG-2 或示波器存的 CSV 拖進來，和模擬波形畫在一起、自動擬合參數（例如 β、電極阻抗）。
價值高（除錯用） · 工作量小

    
更完整的元件模型
Gummel–Poon BJT（Early、接面電容）、二極體串聯電阻與電容、LED、齊納、比較器、ADC 行為模型、電極的 Randles 模型元件。
價值中 · 工作量小到中

    
作業／實驗模式
題目給一個有故障的電路（例如 HW2 的排針沒接好），學生只能「量」節點，靠量測推斷故障點；也能設定通過條件自動檢查。
價值高（教學） · 工作量小

    
極零點、靈敏度、失真
AC 矩陣已經有了：靈敏度用伴隨法一次算出所有元件的 ∂輸出/∂參數；極零點用廣義特徵值；失真用暫態＋FFT。
價值中 · 工作量中
