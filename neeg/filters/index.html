NEEG-2 與 web-neeg 濾波比對

同一個 10 Hz 小 sine：neeg_monitor.py 看不到，網頁版看得到。這頁把兩邊「顯示濾波」的每一步攤開來算，看差在哪。

先講結論。兩邊的三種模式（Off／Remove DC／BP 1–50 Hz）在數學上對 10 Hz 的增益都是約 1.000，也就是說，只要濾波器有正常在跑，10 Hz 小 sine 在兩邊都應該原封不動地顯示出來。 兩邊在算法上唯一會讓 sine「消失」的差別是 NEEG-2 依賴 scipy：如果 import scipy 失敗，BP 模式會不做任何濾波、直接回傳原始值（neeg_monitor.py 第 1676 行），畫面上只剩幾萬 µV 的直流偏移和漂移，Auto Scale 會把 Y 軸撐到漂移的大小，幾十 µV 的 sine 就被壓成一條平線。網頁版的濾波是自己寫的，沒有這個依賴。詳見最後一節「怎麼確認」。

2. Remove DC：一步一步算

概念：「直流」就是訊號的平均高度。把最近一段時間的平均值算出來、從每個點扣掉，剩下的就是上下擺動的部分。

真實程式用 5 秒 = 5 × 125 = 625 個點。為了好算，這裡把視窗縮成 4 個點，批次大小 2。輸入是「直流 1000 µV + 小擺動」：

視窗填滿之後（n ≥ 3）兩邊結果一樣：都是 0, ±10 的擺動。差別只在開頭不滿一個視窗時。對 10 Hz sine 來說，5 秒內剛好 50 個完整週期，平均 ≈ 直流值，所以擺動完整保留。Remove DC 不會讓 10 Hz 消失。

3. BP 1–50 Hz：濾波器其實就是一行「加權相加」

一個二階段（biquad）每來一個新點 x，就用 5 個固定係數 b0, b1, b2, a1, a2 和 2 個記憶格 z1, z2 算出 y：

y  = b0·x + z1
z1 = b1·x − a1·y + z2      ← 留給下一個點用
z2 = b2·x − a2·y           ← 留給下下一個點用

兩邊（scipy 的 sosfilt 和網頁的 Biquad.process）都是這三行。8 階濾波器 = 4 個這種段串起來：第 1 段的 y 當第 2 段的 x，依此類推。

3.3 不用一點一點算：直接算 10 Hz 的增益

Butterworth 的振幅公式（N = 4）：

高通 1 Hz：|H| = 1 ÷ √(1 + (1/10)⁸)  = 1 ÷ √1.00000001 ≈ 1.0000
低通 50 Hz：|H| = 1 ÷ √(1 + (10/50)⁸) = 1 ÷ √1.000256   ≈ 0.99987
兩個相乘 ≈ 0.9999  →  20 µV 的 sine 出來還是 ≈ 20 µV

對照組：1 Hz 剛好在邊緣，增益 1/√2 ≈ 0.707；0.1 Hz 的漂移，增益 = 1 ÷ √(1 + 10⁸) ≈ 0.0001，被壓到萬分之一。兩邊的設計都是這個行為。

3.4 開頭暫態：兩種做法、同一個效果

假設訊號一開始是 50000 µV 的直流。如果記憶格從 0 開始，濾波器會以為「訊號從 0 跳到 50000」，輸出一個好幾萬 µV、要好幾秒才衰減的大突波，把 Auto Scale 撐爆。

  • NEEG-2：zi = sosfilt_zi(sos) × x₀，等於假裝「訊號從很久以前就一直是 50000」，把記憶格預先填成那個狀態，所以不會跳。
  • web-neeg：每個輸入先減 x₀（50000 → 0），濾波器看到的就是從 0 開始；而高通本來就會擋掉常數，所以減一個常數不會改變之後的結果。

兩種做法在穩態下輸出完全相同。

4. 那為什麼 NEEG-2 看不到？

從演算法看，兩邊對 10 Hz 小 sine 都應該顯示得出來。程式碼裡真正會造成差別的只有這條路徑：

# neeg_monitor.py 第 93–100 行
try:
    from scipy.signal import butter, sosfilt, sosfilt_zi
    HAVE_SCIPY = True
except ImportError:
    HAVE_SCIPY = False          # 只印一行 [WARN] 到終端機

# 第 1676 行，BP 模式
if not HAVE_SCIPY or self.sos_bp is None:
    return x1, x2               # ← 原封不動回傳，什麼都沒濾

下拉選單仍然顯示「Filter: BP 1~50 Hz」，畫面上看起來像有濾波，實際上是原始訊號。用數字感受一下 Auto Scale 會發生什麼：

有濾波（web）沒濾波（NEEG-2 缺 scipy）

最大 − 最小40 µV≈ 300 + 40 = 340 µV
Y 軸全幅 = 1.2 ×48 µV408 µV
sine 佔畫面高度40 ÷ 48 = 83%40 ÷ 408 ≈ 10%，再小一點的 sine 就變一條線

電極沒接人體、直接接訊號產生器時，輸入端的直流偏移和漂移可能比上表大得多，sine 佔的比例就更小。

怎麼確認

  1. 從終端機啟動 python gui/neeg_monitor.py，看開頭有沒有 [WARN] scipy 未安裝。
  2. 或在同一個環境跑 python -c "import scipy.signal; print(scipy.__version__)"。
  3. 如果確實缺 scipy：conda install scipy（environment.yml 建立的環境應該已包含）後重開。
  4. 如果 scipy 有裝、BP 下仍看不到，就不是濾波演算法的問題：請比較兩邊在 Filter: Off 下的原始值、確認 Auto Scale 狀態與 Custom Scale 設定，並檢查訊號產生器實際振幅（µV 級需要分壓器）。
