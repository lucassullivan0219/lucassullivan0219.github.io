事件 Marker

    怎麼用（第一次看這裡）
    1. 有腦波帽的人：先拔掉 USB dongle、打開腦波帽。一頂腦波帽同一時間只能連一支手機。
    2. Android：用 Chrome，開啟藍牙和定位，允許 Chrome 使用「鄰近裝置」。iPhone / iPad：Safari 不支援藍牙網頁，請到 App Store 安裝免費的 Bluefy 瀏覽器，用它開這個網址。
    3. 按「連線腦波帽」，在跳出的清單選 STEEG_…。連上後取樣率應接近 1000 Hz。清單裡沒有 STEEG：確認腦波帽已開機、USB dongle 已拔掉、沒有被別人的手機連走，再按一次。
    4. 建議順序：阻抗（調到 < 100 kΩ）→ 訊號（眨眼、咬牙看波形）→ 頻譜 / 頻帶 / 腦地形 / 時頻（閉眼看 α 波）→ 錄製（可下 marker，再下載 CSV）。

    資料只留在你的瀏覽器，錄製檔直接存到你的裝置，不會上傳。手機螢幕關掉時瀏覽器會暫停，錄製時請保持螢幕亮著（連線時本頁會嘗試讓螢幕保持常亮）。
