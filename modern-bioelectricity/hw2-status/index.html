HW2 現況整理（2026-10-12）

給重新規劃網站用的盤點，不求好看。內容依據 git 紀錄（878d56f → 36844c3）、各頁現有內容和對話中的回報。

基礎目標：完整測試助教給的電路（照助教指定，Slow out 的 R2 = 1 MΩ，不加任何外加元件），完成作業每一題，測出什麼就寫什麼。
進階目標：做出真正能模擬 AP 的電路，並具體計算、詳細解釋助教的電路有哪些問題。
目前網站大部分內容屬於進階目標（除錯、模擬、修正方案）；基礎目標需要的「每題的實測數據」幾乎還沒有。見 §4 作業題目進度。

目前架構的混亂點（給改版參考）

  • 同一件事散在多處：PCB 和電路圖的差異（hw2 §3 警告框、debug §2、模擬頁說明）；外加修正（debug §0、§9、§11、hw2 §3 與常見問題、nodes 外加元件表、兩個模擬頁）；#2-3 結果（hw2 §4、#2-3 模擬頁）。
  • hw2 頁混了兩種東西：照講義的操作指引（基礎目標要的），和後來補的除錯／修正結論（進階）。
  • debug 頁是時間順序堆起來的：第一輪的結論在第二輪被推翻、第三輪又找到真正故障，舊段落用「更正」標記保留，讀起來要自己拼。
  • 沒有一個地方記錄「作業每一題的實測數據」，也就是基礎目標的成品。
  • #2-1 完全沒有實測紀錄，也沒有被檢查過是否符合 PCB。
