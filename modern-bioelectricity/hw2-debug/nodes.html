節點命名

HW2 #2-2 active membrane 每一個節點的名稱、它包含哪些焊墊、最好在哪裡量，以及幾種狀態下的預期電壓。回報量測時用這套名稱，就不會搞混是哪塊板、哪一支腳。

命名規則

  1. 格式是「板代號.節點」。板代號：ST = Stimulator、LK = Leak（Passive unit）、FI = Fast inward、SO = Slow out。
  2. 三條經過排針的共用線是 V+、GND、Vm，每塊板上各有一份，例如 FI.V+、SO.GND、LK.Vm。排針接觸良好時，同一條線在每塊板上的電壓都一樣；不一樣就是那塊板的接點有問題。
    • 單寫 Vm 指 ST.Vm：Stimulator 的輸出，也就是 CH1 平常量的點。
    • 單寫 V+、GND 指 Stimulator 電源端子的「+」「−」（ST.V+、ST.GND）。
  3. 電晶體旁的節點用「腳＋型號」命名：3 = 2N3904，4 = 2N4403。B3 是接到 2N3904 base 的節點，E4 是接到 2N4403 emitter 的節點。一個節點同時接兩支腳時取其中一支命名，例如 FI.B4 同時也是 2N3904 的 C。
  4. Stimulator 內部沿電流方向命名：ST.P（SW 之後）→ ST.K（可變電阻和 7K-R1 之間）→ ST.Q（Qpass 的 E）；ST.R 是 Qpass 的 B。
  5. 接點（板子和堆疊之間的排針接觸）寫成「板:線」，例如 FI:V+ 是 FI 板 V+ 那支排針的接觸。
  6. 電壓一律對 GND 量：探棒地線夾夾 Stimulator 電源端子的「−」。兩點之間的電壓寫成相減，例如 FI.E4 − FI.B4。
  7. 方位：元件面朝自己、Intracellular 字樣在上方。TO-92 電晶體：方形焊墊 = E、中間 = B、另一端 = C。二極體有色帶的一端是陰極（PCB 上標「−」）。

照 PCB 實際接法。圖上每個節點旁的藍色字是它的節點名稱（省略板代號，板代號看外框）；紅色斜線處是接點。

每個節點的位置與預期電壓

預期電壓來自模擬（典型元件參數、V+ = 7.8 V、10 MΩ 探棒），讀格子的誤差和元件差異會讓實測差 ±0.1–0.3 V。五種狀態：

A全部接好、SW 放開。模擬時 Vm 會每 0.2 秒左右自己冒一個小峰，所以列「最低–最高」；安靜的電路則停在範圍內某個固定值（模擬中約一半的參數組合是這樣）。 B全部接好、SW 按住（可變電阻轉到電流最大），按住 0.3 秒後。 C只接 ST + LK + FI（沒有 SO）、SW 放開，FI 已自鎖。對應測試 10d。 D只接 ST + LK + SO（沒有 FI）、SW 按住（電流最大）。 EST + LK + FI，但 FI:Vm 斷開、FI 已自鎖，探棒在 FI.Vm。對應測試 4–5。

注意這張表用 PCB 標示的 3M-R2（3 MΩ）計算。助教指定（也是目前電路）的 1 MΩ：B、D 狀態的 Vm、SO.S、SO.B4 約高 0.05–0.07 V，其他節點差異在 0.05 V 內；A 狀態實測約每 0.1 秒冒一個 1.6 V 的小峰。在 Qpass 的 E–B 並 22 kΩ（修正 1，見外加元件）後，A 狀態的 Vm、FI、SO 節點都會變成約 0 V 且不再自發（見除錯分析 §11）。

接點名稱

每塊板經由 1×2 的 Intracellular 排針（Vm）和 2×2 的 Extracellular 排針（V+、GND）接到堆疊上。接點壞掉時，那塊板上的同名節點會和 Stimulator 上的不一樣：

接點正常時壞掉時通常看到
LK:VmLK.Vm = Vm按 SW 時 Vm 幾乎瞬間上升、放開時瞬間掉下（少了 1 µF，就沒有約 100 ms 的 RC 曲線）
LK:GNDLK.GND = 0同上
FI:VmFI.Vm = VmFI 對 Vm 完全沒影響；FI 自己可能鎖在 ½ V+（測試 4–5）
FI:V+FI.V+ = 7.8 V，按 SW 也不動FI.V+ 只有零點幾伏、上下震盪，或跟著 Vm 走（測試 2、7）
FI:GNDFI.GND = 0FI.GND 不是 0 V（浮起來）；FI 沒有回到地的路，不會觸發
SO:VmSO.Vm = Vm按住 SW 時 Vm 停在 5–7 V 的平台；FI 觸發後卡在 3 V（測試 1、9、10c、10d）
SO:GNDSO.GND = 0，按 SW 也不動同上，而且 SO.GND 會被拉高

重點板子是一層一層疊上去的話，某一層的接點壞掉，它上面每一層都會一起斷。回報時順便寫堆疊順序（由下往上），例如「ST / LK / FI / SO」。

回報範例

ST / LK / FI / SO 全接（由下往上），pot 轉到電流最大，SW 按住約 1 秒。CH1 = Vm（1 V/div、20 ms/div）：從 0.6 V 升到 1.6 V 後掉到 0.7 V 停住。CH2 = SO.S（0.5 V/div）：0.55 → 0.69 V。
同上，SW 放開。FI.V+ = 0.4 V 且上下震盪（2 V/div）；V+ = 7.8 V。→ FI:V+ 接點有問題。
ST / LK / FI，SW 沒按。FI.E4 − FI.B4（MATH）= 0.6 V，FI.E3 = 2.2 V，Vm = 3.0 V。→ FI 已自鎖。
