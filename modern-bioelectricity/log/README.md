# Modern Bioelectricity 工作紀錄（log）

這門課的每個指令、每次更動、每個測試結果都記在這裡。平常只看 `INDEX.md`（一行一筆）；要細節再打開月份檔。網頁版：[`index.html`](index.html)。

## 檔案

| 檔案 | 內容 | 什麼時候讀 |
|---|---|---|
| `INDEX.md` | 一筆一行：編號、日期、類型、一句話、標籤 | 每次要找東西時先 grep 這個 |
| `YYYY-MM.md` | 每筆的完整內容，按時間往下加 | 要細節時，用編號跳過去 |
| `media/` | 測試結果的原始照片、截圖（檔名用編號開頭） | 要看原始觀測時 |

## 一筆紀錄

```
## MB-012 · 2026-10-16 · 測試
- 指令：「使用者的原話，一字不改」
- 做了：…
- 結果：數字、波形、結論（原始觀測要留：量到的值、照片檔名）
- 檔案／commit：hw2-lab/index.html、eb0c76a
- 狀態：有效
- 相關：MB-007
```

類型：`指令`（使用者的要求）、`變更`（改了網站或模擬）、`測試`（量測或模擬的結果）、`分析`（解釋、判斷）、`決定`、`更正`、`撤回`、`索引`（指向舊紀錄）。

## 規則

1. **只往下加，不改舊的。** 舊紀錄寫錯，新增一筆 `更正`，舊紀錄只在「狀態」補一句「已被 MB-xxx 取代」。（ADR 的 supersede 作法；ISO/IEC 17025 7.5.2：修改要能追溯到原始觀測，原本的和修改後的都保留。）
2. **使用者要求撤回的內容不保留。** 只記一行「依使用者要求撤回，內容不保留」和 commit 編號，不寫被撤回的內容。（ISO 15489 的 disposition：處置本身要有紀錄。）
3. **編號連續、不重複使用**：`MB-001`、`MB-002`…，跨月份也接著編。
4. **每筆都有**：日期、類型、誰提出（使用者／Claude）、指令原話、結果、檔案或 commit、狀態。（ISO 15489-1：authenticity、reliability、integrity、usability。）
5. **commit 訊息帶編號**，例如 `Modern Bioelectricity: … [MB-012]`，從 git 也能找回來。
6. **測試結果記原始值**，不只記結論；照片存到 `media/`。
